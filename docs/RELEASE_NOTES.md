An initial preview of Photo Sorting Hat: offline EXIF-based photo/video organization, XMP keywords, exact duplicate review, verified Copy/Move exports, a shared CLI, and a desktop interface with day/night themes.

**macOS builds are ad-hoc signed, not notarized.** Use macOS's normal Privacy & Security approval for a trusted app on first launch. No Apple developer account is required.

The automated metadata fixtures pass, but full-camera-image imports into Lightroom Classic and Apple Photos have not yet been manually certified. Review the compatibility matrix before using the app on an archive. Try Copy mode on a small folder first.

Updates are signed independently of Apple and require installation approval. Processing works offline; update checks can be disabled in Preferences.
